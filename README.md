# Arix Alimagnidokpo Portfolio

This project contains the source code for Arix Alimagnidokpo's personal portfolio. It is built with **React**, **TypeScript** and **Tailwind CSS** using Vite.

The website showcases featured projects, research highlights and contact information. Icons are provided by [lucide-react](https://github.com/lucide-icons/lucide) as specified in the project prompt.

## Development

1. Install dependencies (requires Node.js 18+):
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
   The site will be available at `http://localhost:5173` by default.

## Building for Production

To generate the optimized production build, run:

```bash
npm run build
```

You can preview the production build locally with:

```bash
npm run preview
```

## Linting

Run ESLint to check the codebase:

```bash
npm run lint
```
