Les produits
Ayoka, Sovrean

aida.bj

  • Ayoka

    L’API vocale pour les langues africaines

    Reconnaissance et synthèse vocale pour des langues que les grands modèles n’ont jamais apprises. Ayoka connecte 800 millions de locuteurs africains à n’importe quelle plateforme via une seule API.

    • Parole vers texte
    • Texte vers parole
    • Prise en charge des langues à tons
    • API REST
    Précision
    98 % visés
    Langues
    15+, dont fon, yoruba, wolof
    Intégration
    48 heures

    ayoka.aida.bj

  • Sovrean

    Intelligence documentaire souveraine

    Gestion documentaire et intelligence assistée pour les organisations d’Afrique de l’Ouest. Sovrean ingère, structure et classe les archives, puis les rend interrogeables en langage naturel. Rien n’a besoin de quitter le bâtiment.

    • OCR sur scans dégradés
    • Réponses sourcées
    • Rédaction assistée
    • Workflow de validation
    Déploiement
    Cloud, on-premise ou chez le client
    Conçu pour
    Organisations ouest-africaines
    Réponses
    Toujours tracées à un document source

    sovrean.aida.bj
